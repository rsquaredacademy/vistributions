## Supported domain and display precision

The t floor remains `df >= 0.05`. For `0.05 <= df < 1`, percentile plots support the conservative closed interval `0.001 <= probs <= 0.999`, and probability plots require `abs(perc) <= qt(0.001, df, lower.tail = FALSE)`. Errors name `probs` or `perc` and state its valid range, including the numeric cutoff limits for the supplied df. For `df >= 1`, percentiles retain the full open interval `(1e-12, 1 - 1e-12)`; ordinary df >= 1 and probabilities .001–.999 are unaffected. This is a supported joint domain, not a claim to the maximal set of doubles for which an individual plot happens to converge. The guard intentionally avoids extending the numerical algorithm at this release gate.

Only an explicitly supplied chi-square `xaxis_range` is capped at `1e10`. Default body-centred windows are not capped by the value of their right endpoint. Other parameter limits are unchanged. Continuous percentages >= 0.1% retain at least one decimal, including `.0`, with a ±0.05 percentage-point interval at one decimal; exact rounding boundaries can retain more decimals. Smaller percentages and display-floor bounds retain their existing rules.

## Out-of-domain backlog, written out in full

These are future numerical-domain extensions, not unresolved in-domain results. No GitHub issue was opened because this task prohibits GitHub use.

1. **Student's t below the df floor:** support `0 < df < 0.05`, including `vdist_t_plot(.01, FALSE)` and `vdist_t_perc(.95, .001, print_plot = FALSE)`. Currently rejected with a `df >= 0.05` error. Any extension needs event-relative representable-tail coverage and bounded polygon sampling across hundreds of orders of magnitude, not merely a finite qt result.
2. **Extreme percentiles/cutoffs with small supported t df:** extend below `.001` or above `.999` when `.05 <= df < 1`, including `vdist_t_perc(1e-10, .05, "lower", FALSE)` and `vdist_t_perc(1e-10, .1, "upper", FALSE)`, and allow cutoffs beyond `qt(.001, df, lower.tail = FALSE)`, including `vdist_t_prob(1e100, .1, "both", FALSE)`. The explicit joint-domain errors are intentional. A future extension should condition the survival-tail grid and relative truncation budget before relaxing either limit.
3. **Oversized explicit chi-square windows:** support `vdist_chisquare_plot(3, xaxis_range = 1e100, print_plot = FALSE)`. Explicit windows above `1e10` are intentionally rejected by name. Default body-centred windows are already restored independently; this backlog concerns windows starting at zero and spanning enormous empty regions.
4. **Translated normal below the resolution ratio:** support `vdist_normal_plot(mean = 1, sd = 1e-13, print_plot = FALSE)` and corresponding percentile/probability calls. Currently rejected naming `sd / |mean|`, whose documented minimum is `1e-10` for nonzero means. An extension must preserve distinguishable coordinates, ticks and central interval probabilities.
5. **Continuous percentiles at/outside the common probability boundary:** support probabilities at or outside `(1e-12, 1 - 1e-12)`, for example `vdist_normal_perc(1e-13, print_plot = FALSE)` or t at df >= 1 with the same probability. Current errors name `probs` and the open valid range. Infinite endpoint quantiles at zero/one remain a distinct mathematical limit.
6. **Chi-square below its df floor:** support `vdist_chisquare_plot(.01, print_plot = FALSE)` and corresponding percentile/probability calls. Values below `df = .1` are intentionally rejected; extending them requires resolving the singular support edge without dropping its mass.
7. **F below its numerator floor or beyond its concentration limit:** support `num_df < 1`, and concentrated examples such as `vdist_f_plot(1e9, 1e9, print_plot = FALSE)` whose central 99.9998% width is below `.001`. Current errors identify `num_df` or concentration. An extension must keep both the density and probability-space polygon meaningful at the rendered scale.
8. **Normal scales beyond finite-density/range limits:** support zero-centred scales below about `1e-308`, or ranges such as `vdist_normal_plot(sd = 3e307, print_plot = FALSE)` where `8 * sd` overflows. Current errors identify the finite-density or representable-window limit. A future implementation would need rescaled rendering as well as rescaled probability calculations.
